<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Public HTTP → Fastify route | Untrusted internet input: headers, IP, path params |
| req.ip → rate-limit key | With `trustProxy: true`, Fastify trusts `X-Forwarded-For` — only safe behind a trusted proxy (Caddy/k8s ingress per PROJECT.md Hosting) |
| Bearer token → memory compare | Side-channel exposure if compare is data-dependent |
| Probe results → JSON/markdown body | Must not include raw secrets even transiently |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-10 | Spoofing | bearer auth | mitigate | `crypto.timingSafeEqual` on length-matched buffers; dummy compare on length mismatch (D-09); `parseBearer` rejects non-Bearer schemes |
| T-10-11 | Repudiation / Auth bypass | 503-gate ordering | mitigate | Pre-handler runs `!env.DIAGNOSE_TOKEN → 503` BEFORE auth — prevents accidental "no token configured ⇒ no auth required" footgun (D-07) |
| T-10-12 | Denial of Service | rate-limit bypass via IP spoofing under `trustProxy: true` | accept | Deployment constraint: only deploy behind a proxy that strips/sets `X-Forwarded-For` correctly (Caddy/k8s); documented in README per Phase 11. Without trustProxy, ALL requests share `req.ip = socket address of proxy` and one IP exhausts global budget — worse failure mode |
| T-10-13 | Information Disclosure | response body redaction | mitigate | Notify section reads only `healthChecker.getStatus()` enum (D-17); redactSlackUrl/redactSecret used for any field that touches env values; tests assert literal token absence |
| T-10-14 | Tampering | `req.params.owner`/`repo` passed to Octokit URL | mitigate | Octokit performs URL-encoding; no shell-out; no SQL; path-traversal not applicable. Probe failures surface as ProbeStatus 'error', not crash |
| T-10-15 | Elevation of Privilege | diagnose endpoint as info-disclosure on internal env | mitigate | Bearer required (DIAG-02); 503 when unset prevents accidental anonymous exposure; rate-limit caps probing throughput (DIAG-03) |
</threat_model>
