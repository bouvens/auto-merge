| GitHub response → DiagnoseReport | Inbound; payload shapes assumed (permissions object, default_branch field) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-05 | Denial of Service | runProbes outbound calls | mitigate | Per-probe `AbortSignal.timeout(3000)`; total bounded by `Promise.allSettled` of ~6-8 calls = max ~3s wall-clock |
| T-10-06 | Tampering | GitHub response field assumptions (`permissions`, `default_branch`) | accept | Trust boundary: GitHub is upstream of record; missing fields surface as ProbeStatus 'error' via safeProbe, never crash |
| T-10-07 | Information Disclosure | log.warn on probe failure includes owner/repo (not secrets) | accept | Owner/repo are already in URL path; no token/secret leak path in error message (Octokit error messages are upstream-controlled but never include our credentials) |
